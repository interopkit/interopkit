Every function is named by what it does, with one verb for one meaning: `hashAttachment` (was `attachmentHash`), `isSameStatement` (was `sameStatement`), `convertStatementVersion` (was `toStatementVersion`) and `buildVoidingStatement` (was `voidingStatement`). A function that reads or writes a form that a standard defines is named `read` or `write`, one that assembles plain data `build`, one that returns an object with behavior `create`, one that answers an HTTP request `handle`, a lookup `find` or `list`, a predicate `is`, and no old name is kept as an alias.
